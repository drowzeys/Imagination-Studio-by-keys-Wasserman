# Security and contact

Imagination Studio by keys+Wasserman is reached through GitHub only. No email address is published for it, on
purpose.

- **A security problem** (a way in from the network, a leaked key, a route that writes without the guard): report it
  privately on this repository's **Security** tab, *Report a vulnerability*. Only the maintainers see it. Please do not
  open a public issue for it.
- **A bug, or something that does not install:** open an **Issue**, with the machine (Mac chip and memory, or DGX
  Spark), the Studio version (Settings → About) and what the app or the installer said.
- **A question, an idea, something you made with it:** **Discussions**.

Never paste a token, a key, a password or your own address into any of them: the Studio never needs one from you to
help.
